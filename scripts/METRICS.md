# Metrics dashboard

The README dashboard uses real public data from
[rdme0's Metrics Insights](https://metrics.lecoq.io/insights?user=rdme0).
Its isometric calendar SVG is generated by Metrics. The surrounding layout,
language donut, and theme colors are customized for this profile.

The hosted image renderer returned HTTP 500 during setup, with an `ENOSPC`
error in the Insights response. The working Insights JSON endpoints supply
the calendar, language sizes, and authored issue / pull request counts instead.
This integration does not require a personal access token.

Install the renderer:

```sh
python -m pip install -r scripts/metrics-requirements.txt
python -m playwright install chromium
```

Refresh and render:

```sh
python scripts/render_metrics.py --refresh
```

Render the saved snapshot without fetching new data:

```sh
python scripts/render_metrics.py
```

To use an already installed Chrome browser, append `--browser-channel chrome`.

The workflow refreshes daily at 06:17 Asia/Seoul after being pushed to the
repository's default branch. It can also be run manually. Failed data fetches
leave the last generated dashboard in place.

Language shares measure code size in owned repositories, not proficiency.
The calendar and its longest streak cover the previous year; authored issue
and pull request totals cover the account's history. The footer records the
fetch date in Korea Standard Time.
